# TRMNL fonts

The TRMNL font family, designed by Heavyweight Digital Type Foundry and commissioned by TRMNL. Source: https://trmnl.com/font-family

Files (TRMNL12, TRMNL16 and TRMNL21, each in Regular and Bold), downloaded on 2026-10-21 from:

- https://trmnl.com/fonts/TRMNL12-Regular.ttf and https://trmnl.com/fonts/TRMNL12-Bold.ttf
- https://trmnl.com/fonts/TRMNL16-Regular.ttf and https://trmnl.com/fonts/TRMNL16-Bold.ttf
- https://trmnl.com/fonts/TRMNL21-Regular.ttf and https://trmnl.com/fonts/TRMNL21-Bold.ttf

The page lists no version number.

Licence: the page says the fonts are "free to use in anything, commercial projects included". No named licence file is published.

Usage: each cut is a pixel-grid font with a native size (12, 16 or 21). Render it only at that size or an exact integer multiple (for example TRMNL16 at 32), at 1 bpp, so every stroke stays on whole pixels.
